# DMIT 折扣碼：年付 7 折、季付 8 折的循環碼怎麼疊，LAX／HKG／TYO 三地線路與方案價格一次看懂

會來搜「DMIT 折扣碼」的人，心裡想的通常很單純：有沒有那種貼上去、結帳金額立刻少一截的碼。

先把話說在前面：DMIT 沒有全站通用的一組折扣碼。它的碼綁三個變數——機房、線路、付款週期。搞懂這三件事之後，你會發現能用的碼其實不多，但幅度不算小，而且有幾組是**循環折扣**，意思是續約那年再省一次，不是只有第一期便宜。

## 沒有通殺碼，因為 DMIT 賣的不是同一種東西

DMIT 的產品線同時有三條網路在跑：

- **Tier 1（T1）**：純國際 BGP，沒有針對中國大陸做特殊優化，價格最低、頻寬與流量給得最大方
- **Eyeball（EB）**：走 CMIN2／9929 這類中國方向的優化線路，比 T1 貴一些
- **Premium（Pro）**：CN2 GIA 等級的骨幹，三地（洛杉磯、香港、東京）都有，單價最高

同樣是 2 核 2G，Pro 和 T1 的價差可以到好幾倍，差別全在回程路由。折扣碼在這種架構下就是行銷工具：庫存積著、或新線路上線要衝量時才發碼；熱門款根本搶不到貨，自然也不需要打折。

付款週期同樣綁死。絕大多數 DMIT 折扣碼明文要求季付以上，月付不適用；而像 WEE 這種最低價的入門款，也常常被直接排除在適用範圍外。所以「這組碼沒用」的常見原因不是碼過期，是你買的方案或週期根本不在名單裡。

### 三種折扣形式，別搞混

- **循環折扣（Recurring）**：折扣跟著產品走，每一次帳單週期都適用，續約繼續便宜。上面標「循環」的都屬於這種，長期算下來差最多。
- **一次性折扣**：只砍第一期帳單，第二期回到原價，適合拿來試水溫。
- **帳戶金返還**：聖誕檔期的做法是「折扣＋返還」並行，例如年付 STARTER 以上方案給 15% 循環折扣，再額外把實付金額的一部分以帳戶餘額形式分 12 個月攤還。聽起來划算，但**返還的是帳戶金，不是退到你信用卡**，等於把錢鎖在 DMIT 帳號裡，除非你本來就打算續約，否則別把它當成折扣算。

## 折扣碼怎麼用：三個步驟，加上最常見的三個卡點

1. 進結帳頁，先選好**機房、線路方案與付款週期**。順序不能顛倒，因為碼是看這三項決定收不收。
2. 在 promo code 欄位填入折扣碼，按 **Validate Code**，讓系統確認。
3. 確認折後金額再付款。DMIT 支援信用卡、PayPal、支付寶，部分時期也收微信支付。

卡點幾乎都集中在這裡：

- **碼沒反應**：多半是月付方案。換成季付或年付再試。
- **碼顯示無效**：你買的是 WEE 這種最低價款，或該碼只限特定機房。
- **折了第一張單、續約恢復原價**：你用到一次性折扣，不是循環折扣。

## 折扣碼該留給哪條線路

如果你只是要多一個海外節點跑 CI/CD、備份、監控，或做純國際流量，**不需要浪費折扣碼在 T1 上**——T1 的 WEE 年付 US$36.9 本來就是 DMIT 的地板價，這條線很少另外發碼。反過來說，若為了省錢買 T1、卻拿它來服務大陸訪客，錢是省了，體感會直接反映在晚高峰。

折扣碼真正值得花力氣的地方在 Pro 與 EB。這兩條線單價高，10% 到 20% 的循環折扣換算成年費差距很具體：香港 Pro.TINY 月付 US$39.90，一年下來接近 US$480，扣掉兩成的循環折扣就是將近 US$100 的差別，而且往後每年都省。EB 的定位介於中間——比 T1 貴、比 Pro 便宜，用 `LAX-EB-LAUNCH-NON-MONTHLY-RECURRING-20OFF` 拿 8 折之後，性價比是洛杉磯這批方案裡比較好算的一組。

還有一種情況是「根本沒有碼可用」。DMIT 有時直接把折扣做進定價，例如洛杉磯 Premium 線曾出現 TINY 年付 75 折、其他方案年付 9 折、完全不需要輸入折扣碼的安排。所以找不到可用的碼，不等於沒便宜，先看方案本身的年付價是怎麼開的。

## 下單前該知道的限制

- **流量用完不停機，改限速**。不同方案的限速值從 4Mbps 到 100Mbps 不等，T1 系列尤其明顯——這是 DMIT 相對其他家比較實用的一點。
- **月付方案的 IP 不保證全球可用**。想確保拿到能用的 IP，下單時多花 US$1 加購 Guarantee；買完才發現 IP 不能用，換 IP 要付 US$5。
- **庫存是浮動的**。洛杉磯、東京都出現過「有價無貨」的狀態，補貨往往集中在特定時段，賣完為止。看到有貨就別拖著研究三天。
- **AS3 平台處於持續優化階段**。官方對洛杉磯 AS3 提示過磁碟效能與 SLA 可能低於成熟平台，重要業務上線前建議先自行測試。
- **付款方式**包含信用卡、PayPal、支付寶，部分時期支援微信支付。

## 常見問題

**折扣碼可以跟帳戶金返還一起用嗎？**
聖誕檔期的設計就是「折扣碼＋帳戶金返還」同時生效，返還金額依付款週期計算，分 12 個月攤還。返還的是帳戶餘額，不是現金回饋。

**為什麼我輸入 `Lite-Annually-Recur-30OFF` 沒反應？**
先確認你買的是不是 Standard Network、方案層級有沒有到 STARTER、週期是不是年付。三個條件缺一個就會被系統拒絕。

**同一組碼可以重複用嗎？**
循環折扣的意義就在這裡——它不是優惠券，而是綁在產品上的長期折扣，續約帳單會自動套用。一次性折扣則只作用於第一張帳單。

**現在最新的檔期活動去哪裡看？**
活動頁與庫存都在官網，折扣碼的適用範圍也會寫在活動說明裡。直接看官方公告會比看整理文章準，因為活動結束後第三方頁面通常不會即時更新。
